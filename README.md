# Student Performance Analysis

## Overview
This project explores factors that influence student academic performance using a real-world dataset.

The analysis focuses on how study time and absences relate to final grades, using Python for data analysis and visualisation.

---

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn

---

## Dataset
The dataset contains student information including:
- Study time
- Absences
- Previous grades (G1, G2)
- Final grade (G3)

---

## Key Analysis

### Study Time vs Performance
Students with higher study time levels generally achieve higher average final grades, indicating a positive relationship between study effort and academic performance.

### Absences vs Performance
A negative relationship is observed between absences and final grades, suggesting that higher absences are associated with lower academic performance.

### Correlation Analysis
- Study time shows a positive relationship with final grades  
- Absences show a negative relationship  
- Previous grades (G1 and G2) have the strongest correlation with final performance  

---

## Visualisations
The project includes:
- Bar charts (study time vs grades)
- Scatter plots with regression lines (absences vs grades)
- Correlation heatmap
- Grade distribution histogram

---

## Conclusion
This analysis suggests that study habits and attendance are important factors associated with academic performance.

Students who dedicate more time to studying and maintain consistent attendance tend to achieve better outcomes. However, further analysis would be required to establish causation.
